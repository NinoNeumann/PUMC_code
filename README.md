# PUMC CACox 分析代码

本仓库归档基于 `20261027v2.xlsx` 的主分析、敏感性分析与亚组分析代码。

| 工程 | 内容 |
| --- | --- |
| [主分析](main_analysis_20261027v2_code/README.md) | CACox 与 RCS＋ridge-Cox 的 10 次重复五折分析，含每折 20 份插补及配对比较代码。 |
| [敏感性与亚组分析](sensitivity_subgroup_20261027v2_code/README.md) | 五分支敏感性分析、MPA/GPA 亚组和肾脏受累亚组的代码。 |

各工程的 README 说明运行顺序、依赖和源码溯源。研究数据、模型权重、预测与结果保存在原归档中。复现分析需要在获授权的环境中提供相应数据和依赖，并配置路径。工程中的历史路径用于定位原始归档。
