# CACox CUDA 小预算验证

本实验独立于已终止的 `cacox_rank_forest/20261030_v1`；不得恢复该CPU全量任务。

## 预注册协议

- 保持1140人、全部五外折和五内折、R MICE缓存、Boruta+LASSO名单15/9/8/9/8、原始CACox参数和权重不变。
- 插补编号固定为1、2、3，不根据内外层成绩或插补值挑选。共75内部单元、15外层单元；不是完整5×20验证。
- 两个方向分别为GPU直方图排序修正树、GPU直方图随机生存森林；每方向使用原CPU实验的四种深度/叶大小配置。排序树计数0/75/150/300/600，森林300棵；不追加搜索。
- 所有内部配置在任何本轮外层预测前冻结。内部不以外层成绩作预算门控；两方向均完成预定15个外层单元。
- GPU排序树：XGBoost CUDA hist + 自定义可比较生存对softplus负梯度；单位曲率作为一阶梯度提升的工作权重，不声称是真实Hessian。不使用原生rank:pairwise替代删失规则。固定0.5 CACox原始log风险作为base_margin。
- GPU森林：PyTorch CUDA批量建树，训练分区分位数直方图、bootstrap、sqrt随机特征、log-rank分裂、叶Kaplan-Meier生存曲线。与scikit-survival精确阈值版本不是逐位等价实现；固定32箱，所有折点只用训练分区。使用同一组随机计划验证CPU/CUDA实现，而不要求与原库结果相同。
- 组合：排序修正树保留0.5 CACox风险偏置；森林固定50% CACox生存概率+50%森林生存概率，风险=1-S(730)。不重训CACox。
- 比较普通Cox、匹配RCS、原始CACox、原J3、C2、迁移前CPU排序树/生存森林与两种CUDA新实现。历史参考统一截取相同15外层单元；CPU两方向仅在75个预定内部单元选参，重新拟合15个外层单元。
- CUDA/CPU同实现数学、删失/并列、log-rank oracle、保存恢复、推理设备、训练/推理计时及完整性验证独立记录。CPU/CUDA精度及预测差如不为零须如实记录。
- 95%区间沿用既有按患者影响函数及多重插补合并程序，m=3；区间为同队列开发下的条件推断，不能消除多轮查看外层、固定筛选名单和早停缓存造成的依赖；15个插补模型并非15个独立队列。

结果目录：`results/cacox_cuda_pilot/20261030_v1`。实验日志记录时间、目的、参数、结果路径和说明。任何GPU性能收益必须用实测说明；小数据上可能更慢，不承诺C-index提高。
